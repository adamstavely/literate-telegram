Interop Design System

The look of a registry
that makes the stack work together.

Interop is the interoperability layer for agents — MCP servers, APIs, tools, skills, and agents in one governed catalog. This guide documents the brand: one calm monochrome canvas, one decisive accent, and a precise, engineered voice.

00 Principles The instincts behind every screen.
Monochrome, one accent
A near-black ink on white, with a single electric blue for action and emphasis. Color is information, never decoration.
Engineered, not loud
Tight letter-spacing, monospace for identifiers, generous whitespace. It should read like good infrastructure: precise and quiet.
Governed by default
Badges, sensitivity tiers, and verification marks carry real meaning. Every signal maps to a governance concept, not a vibe.

04 Voice & Tone How Interop sounds: like an engineer you trust, not a brand selling to you.
Precise
Name things exactly. A tool is a tool, a server is a server, a skill is read not called. Borrow the spec's vocabulary; never blur it for a smoother sentence.
Plain
Short, declarative sentences. Cut adjectives and hype. If a word isn't load-bearing, delete it. Clarity is the whole brand.
Trustworthy
Lead with what's governed and why. Say what a thing does, what it can reach, and the risk — calmly, without alarm or salesmanship.
Do & don't
Do
Use the real noun. "This server exposes 12 tools." Precise terms build trust with a technical audience.
Lead with the verb. "Connect a client," "Publish a skill," "Review the queue." Start with the action.
State the governance. "Held for review until an admin approves." Name the rule and the reason.
Write tight identifiers. Lowercase, mono, exact: anthropic/github, create_issue.
Don't
Reach for hype. No "powerful," "seamless," "revolutionary," "supercharge." It reads as marketing, not infrastructure.
Blur the object types. Don't call a skill a "tool" or an agent an "app." The distinction is the product.
Manufacture urgency. No exclamation marks, no "Act now." Risk is stated plainly, never dramatized.
Over-explain. Don't pad with throat-clearing like "In order to…" or "It's important to note that…".
Say this, not that
Not this
Supercharge your AI with our powerful, seamless integrations!
Say this
Connect MCP servers, tools, and skills from one governed catalog.
Not this
Oops! Something went wrong. Please try again later.
Say this
This server failed to respond. Check its endpoint and retry.
Not this
This amazing tool lets you do tons of cool stuff with your data.
Runs a read-only SQL query and returns rows. Cannot write.
Not this
Get started in seconds — it's super easy!
Say this
Three steps: discover, connect, use.
