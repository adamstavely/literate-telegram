-----------------------------------------------------------------------------
 Backend API
-----------------------------------------------------------------------------

To test the health endpoint from inside the cluster (via the frontend pod — arbitrary debug pods are blocked by NetworkPolicy):

  kubectl exec -n {{ .Release.Namespace }} \
    deploy/{{ include "interop.fullname" . }}-frontend -- \
    wget -qO- http://{{ include "interop.backend.serviceName" . }}:{{ .Values.service.backend.port }}/api/health/ready

-----------------------------------------------------------------------------
 Seed data (first install only)
-----------------------------------------------------------------------------

A post-install Job was created to seed the Elasticsearch indices.
Check its status with:

  kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl logs -n {{ .Release.Namespace }} job/{{ include "interop.fullname" . }}-seed

-----------------------------------------------------------------------------
 Secrets
-----------------------------------------------------------------------------

Update the backend secret with real credentials:

  kubectl create secret generic {{ .Values.backend.envSecret }} \
    --namespace {{ .Release.Namespace }} \
    --from-literal=ES_PASSWORD='<your-password>' \
    --from-literal=OIDC_ISSUER='<issuer-url>' \
    --from-literal=OIDC_AUDIENCE='<audience>' \
    --from-literal=OIDC_JWKS_URI='<jwks-uri>' \
    --dry-run=client -o yaml | kubectl apply -f -
