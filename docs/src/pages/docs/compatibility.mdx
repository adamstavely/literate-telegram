## The compatibility axis


Each server lists the clients it's been verified against. Skills are more portable — any agent that implements the skills format can read any SKILL.md — but the index still records where each has been exercised.

## Filtering by client


Use the **Compatible with** filter in [Browse](/) to narrow the catalog to entries your client supports. The compatibility badges on each detail page tell you what's been verified.
